# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within the MARTIAN engine, please do not disclose it publicly via issue trackers.

Please report security vulnerabilities directly to the maintainer via GitHub Private Vulnerability Reporting or via email. You will receive an acknowledgment within 48 hours with a coordinated disclosure timeline.
